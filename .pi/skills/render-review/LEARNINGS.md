Oversize for WhatsApp → send the file on his web chat instead.
- 2026-09-26 Modal reuses warm containers: _prep skipped re-extract when /tmp/studio existed, so a reused container could render the PREVIOUS call's studio tree and ship its old frames (v3 returned 471 jpgs for 314). _prep now wipes /tmp/studio each call; after any farm render, diff a changed frame against the prior version to prove the new code rendered.
- 2026-09-26 Pure Canvas2D motion-graphics pages render locally at ~19 fps (2 workers) — no farm needed; the 75 s/frame figure is only for p5.brush watercolor.

- 2026-09-26 "Original" needs a live comparison, not memory: the quick check is our contact sheet beside this fortnight's whatships launch wall (whatships.py wall) — the trend moves weekly.
- 2026-09-26 Cutting between two shots of the same performer reads as a jump when the eyes change height; check eye-line continuity at every performer→performer seam (from Mirage's Tesseract editing guide; the principal approved this one point only).
- 2026-09-27 On the CPU box, HyperFrames `--quality draft` only swaps the encoder (ultrafast CRF 28); screenshot capture (~2.5-3 fps at 1080p, 2 workers) is the whole cost. For long local renders go straight to `--quality looks` (CRF 16): the review copy can be the master if it passes. Multi-worker mp4 needs `HF_CAPTURE_PARALLEL_STREAM=true` or it dumps every frame to disk (~1 MB/frame).
- 2026-09-27 A GSAP/HyperFrames comp that is a pure function of time renders on Modal CPU containers with `scripts/modal_hf.py` (seek the registered timeline + screenshot + per-chunk x264, local lossless concat + master-audio mux): 0.35 s/frame per container, a 5.5-min film in ~5 min on 25 containers vs 96 min locally. Verified parity against the local HyperFrames master: time-aligned, PSNR 35-37 dB, difference = uniform encoder noise (mean 2.5/255), no structural change. Keep `-tune animation` off on vellum/grain textures (it doubled the bitrate).
- 2026-09-27 The whole-film strip (1 frame / 2 s) caught what 110 hand-picked stills missed: three 1.5-2 s blank pages under live narration at scene seams. Always sample the seams at 0.5 s after a strip flags one; an empty page while the narrator talks reads as a dropped shot, not a breath.
- 2026-10-01 modal_hf.py captured a fixed 1920×1080 viewport, so a 9:16 comp rendered cropped; it now takes --width/--height (defaults unchanged). Pass the comp's frame size for every non-16:9 cut. (First try failed every chunk: the new `w` parameter was shadowed by `with wave.open(...) as w` in the same function, so Chrome got a Wave_write object as its width. Name parameters `vw`/`vh` there, and on a whole-farm failure run a 0.05 s single-chunk test that prints the args.)
- 2026-10-06 send_file limits: WhatsApp 16 MB, web chat 64 MB. A 1080p60 CRF 15 master with full-frame camera motion runs ~36 Mbps (22 s = 94 MB) and fits neither. Before the master render, compute size = bitrate x duration; if it will pass 64 MB, ask the principal for the route (CRF 18 one file, lossless split, other) before rendering, not after.
- 2026-10-07 WebGPU comps render on Modal CPU containers: `modal_hf.py --webgpu --cpu 8` adds SwiftShader-Vulkan WebGPU flags and awaits window.__hfShadersSeek(t) after each timeline seek. LEVELS (972 1080p30 frames, 23 shader presets) took 110 s wall on 32 chunks, 0.34–3.1 s/frame. The ANGLE-SwiftShader GL flags present an empty WebGPU canvas; `hyperframes render` rejects fallback adapters.
- 2026-10-07 Cancelling a local `modal run` (execution_cancel) does not stop its ephemeral app: 30 containers kept running. Run `$PY -m modal app list`, then `modal app stop <id> --yes` (without --yes it aborts: no TTY).
