Two in three sensor turns end with nothing to do

Agents write small programs, called sensors, that check a system on a timer and wake the agent when something changes. We read every sensor we could find and sorted them into eight patterns. Most sensors fire on new items, and most of the turns they start find no work.

71%of the agent turns that sensors start end with nothing to do.

61%of sensors run every five minutes or more often.

44%of sensor turns happen outside office hours or at the weekend.

The basics

What a sensor is

Schedules fire on the clock, people chat, and sensors trigger on change. The platform runs a sensor every few seconds up to once a day.

Each tick is one run of the sensor’s code. Orange runs found something and fired.

We describe each sensor by what it checks, what makes it fire, and what happens next. New items lead by a wide margin.

Pattern 1 of 8

New items

The sensor reads a list and fires once for each item it has not seen before.

An inbox

Keep a cursor and fire only for items after it. On the first run, set the cursor without firing.

  1. Photos from kitchen stations. One sensor per chat group sends new photos to the agent that records them.
  2. Invoice requests. Guest messages asking for an invoice go to the agent that handles accounting.
  3. Merged pull requests. Everything merged since the last run goes into one hourly summary.
if (!cursor) return { newCursor: Date.now(), events: [] }  // first run
const fresh = await inbox.list({ since: cursor })
return {
  newCursor: fresh.at(-1)?.receivedAt ?? cursor,
  events: fresh.map(m => ({ id: m.id, prompt: `New mail from ${m.from}` })),
}

Method

How we counted

Unit
A sensor at an organization. A run is one execution of its code; a turn is the agent’s work after it fires.
Source
Sensors rebuilt from agents’ reads of their own sensor lists; fires from conversation logs; turn outcomes from the Agent Work Index task codes.
Weighting
Each organization counts equally. Codes seen at too few organizations are shown as n/a.
Coding check
A fresh random sample agreed 93% on what it checks, 96% on what makes it fire and 90% on what happens next.
Excluded
Tests and empty stubs. Examples are paraphrased with names removed, and code sketches are rewritten.

Shares are of sensors at a typical organization and may not sum to 100 because of rounding.
