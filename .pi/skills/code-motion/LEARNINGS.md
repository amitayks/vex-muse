# LEARNINGS — code-motion

- 2026-09-26 Chrome on this box fails URL font loads (NetworkError, even data: URIs) and has no system fonts: register every face from bytes (FontFace(ArrayBuffer)) or text renders blank.
- 2026-09-26 HyperFrames workers seek frames in parallel: a timeline built inside fonts.ready leaves early frames at CSS initial state — register synchronously.
- 2026-09-26 GSAP fromTo pre-renders its from-state before its start time when seeked (flash at full opacity from frame 0, shockwave blob): drive custom effects as pure functions of t from one proxy tween.
- 2026-09-26 clip-path:url(#svgClipPath) on a wrapper around a <video> blanked the plate in capture; a CSS path() rebuilt per frame works.
- 2026-09-26 HyperFrames preview writes data-hf-id into project HTML and lint errors on two root compositions in one dir: keep sources in <comp>-src/, build in.
- 2026-09-26 A dot that floats for a bar before landing reads floaty: bring the motif back for ONE beat and land it on the downbeat.
- 2026-09-26 mix-blend-mode:difference on HUD text turns it cyan on red fields: set the HUD colour per field instead.
- 2026-09-26 Tweening fill between flat inks passes through mud (red→blue = purple): switch fill hard at the morph midpoint.
- 2026-09-26 The template/brief had hard-coded the studied trend's look as defaults: principles are portable, looks are not — keep templates as mechanics only.
- 2026-09-26 Beat snapshots passed but the turn's mid-motion swing crossed the caption at 6.5 s (found only in the frame study): measure a moving object's envelope over every frame before placing text.
- 2026-09-27 HyperFrames' runtime executes external `<script src>` files before the body exists (validate: "Cannot read properties of null (reading 'appendChild')"), while direct Chrome runs them fine: keep DOM-building code inline at the end of body (inline it at build time) and register the timeline in that same script (lint wants create + register together).
- 2026-09-27 `mix-blend-mode:multiply` on images inside a transformed camera div blends only inside the camera's stacking context (white paper showed as a light box): put the blend on the camera group itself so it multiplies onto the page.
- 2026-09-27 When a snapshot is blank but the page renders in plain Chrome, run `hyperframes validate/check` first — it reports runtime JS errors the snapshot hides.
- 2026-09-27 Word-by-word caption spans with `white-space:pre` and the space inside the span leave no break opportunity: the line never wraps and runs off-frame. Keep words `nowrap` and put the space as a text node between spans.
- 2026-09-27 A dark scene whose camera group multiplies onto a dark page turns every drawing black: multiply the camera only onto light pages.
- 2026-09-27 `hyperframes snapshot` took ~40 s/frame on a 5-min comp; a puppeteer seek of the built index.html (tl.seek + screenshot) took ~0.6 s/frame and matched — use it for review sweeps, snapshot/check for the gate.
- 2026-09-27 Old-style display fonts (IM Fell) have no Greek: any non-Latin line needs a face that covers it (EB Garamond) or it renders tofu.
- 2026-10-01 A per-frame proxy tween at time 0 renders BEFORE later-starting tweens in the same seek, so f(t) effects (camera, plates, clips) read the previous seek's values — one frame behind. Drive per-frame code from `tl.eventCallback('onUpdate')`, which fires after every child rendered; extend the timeline with `tl.set({}, {}, DUR)`.
- 2026-10-01 On a board of stacked full-frame rows, ambient camera drift by translation exposes the next row's colour at the frame edge: ambient motion there is a push-in (scale), never a translate.
- 2026-10-01 Whip motion blur that survives seek capture: SVG `feGaussianBlur stdDeviation="0 σ"` as `filter:url()` on the stage, σ from the whip ease's speed curve (power3.inOut → 4p² / (2−2p)²), none between whips. Reads as a camera whip, costs nothing visible on 2 CPUs.
- 2026-10-01 A `const` used before its declaration in the timeline script (TDZ) throws before `window.__timelines` is set, so every snapshot and Modal chunk fails: keep shared times at the top of the script.
- 2026-10-01 A 9:16 cut of a split-screen comp is a re-layout, not a crop: turn the seam horizontal and show each 16:9 half through its own "virtual" layer (half authored size, uniform scale, seam on the screen's midline) so the half's layout survives untouched. Objects that cross the seam become twins whose authored horizontal moves are mapped at build time to moves between the stacked halves (`motion/make_vertical.py`, aharonis-shift-handshake). Keep the 9:16 file generated from the 16:9 source so the two never drift apart.
- 2026-10-06 Agent cursors were hand-tweened (linear move + scale on click) and read as fake; human cursor motion is a solved, vendored library now (Cua motion lab): retime its moves so clicks land on beats, never retime by stretching a whole path uniformly — keep the move's own speed and wait before it.
- 2026-10-06 Full-frame grain that moves every frame at 60 fps is fresh noise in every frame: the delivery encode of a 22 s comp ran 10+ min and passed 119 MB (vs 72 s / 5.9 MB without). Step the grain offset at film rate (12-24 fps: seed = floor(t*12)), never per frame.
- 2026-10-07 A WebGPU library with its own rAF clock (shaders@4) is made frame-exact by seeking to an ABSOLUTE time (dt = T − engine elapsed, signed) and by starving its requestRender: a stray wall-clock render landed between seek and screenshot (+0.03 s). Prove determinism with shuffled-order seeks hashed against sequential ones before any render.
- 2026-10-07 A hero 3D ring that spins freely turns edge-on and reads as a pill (v1 full Y spin, and v2's "in-plane" Z spin too: in shaders@4 every Euler angle tilts the torus axis, +Y by default). Bound every angle near face-on (rotX 90±25, rotY/rotZ ±18) and sample the pose over the whole timeline in node before rendering.
- 2026-10-07 Inlining third-party libraries (GSAP, engine bundles) into the comp makes `hyperframes lint` fail on their internals (Math.random, rAF, performance.now): keep libraries as external <script src> (they build no DOM at load) and inline only comp code.
- 2026-10-07 An opening that grows from zero (iris r=0, number sliding in) makes frame 0 black, and frame 0 is the thumbnail and the autoplay still: the first scene is whole at frame 0 and lands with the first downbeat; entrances start from the second scene.
- 2026-10-07 An end card that starts building on the last downbeat of a section holds only ~1 s before a hard section end: extend the audio cut 1–1.5 s into the next section under a 1 s fade so the full card holds ≥1.5 s.
- 2026-10-07 A plate that runs below 1x (0.8-0.85x to stretch a 5 s plate) repeats a frame every 5-7 frames: visible judder on slow camera moves. Draw fractional plate time as a blend of the two neighbour frames (globalAlpha = frac), or keep plates at 1x and re-time the edit. Scan every render for diff < 0.02 at 240x135 to find these.
- 2026-10-07 A layout scene where cards land and then wait reads as a frozen frame (161 duplicates over 6 s on a real-estate cut, version B). Keep a slow camera drift over any built page for its whole length, and let the last element's zoom end exactly on the cut.
- 2026-10-07 PDF brand fonts are subsets: rebuild them as OTF with fontTools (CFF -> FontBuilder, widths from T2WidthExtractor with the Private nominal/default widths), then check every on-screen string against each face's cmap before render. Missing glyphs are common (one brochure: ן, ס, ז, ג, digits in Bold, & in EnXL).
