Judge a design sheet for a set, a location or a vehicle (several views of one place or one machine) for a photoreal film made with image and video models. Score 0-10; pass only if every item is 7 or more.
1. identity: the same place or machine in every view (shape, proportions, colours, livery, number of engines/propellers/wheels, landmarks). Name any view that drifts.
2. realism: it looks like a real, practical place or a real working machine photographed on film; no CG gloss, no toy look, no impossible parts.
3. readability: it reads at phone size in one glance; the silhouette and one signature colour or shape are clear.
4. fit: it matches the brief and the project bible (era, palette, light, world); no real-world markings, text, numbers or insignia.
5. usability: the views cover the angles the script needs, with clean light and space for action, so video models can start shots from them.
